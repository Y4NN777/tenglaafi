À propos

Le projet TengLaafi

TengLaafi — "santé" en mooré — est un assistant médical spécialisé dans les maladies tropicales et les plantes médicinales africaines.

Il combine la recherche augmentée par génération (RAG) avec une base de connaissances de 1 500+ documents provenant de sources médicales reconnues : OMS, PubMed, et des publications académiques.

Notre mission : rendre l'information médicale accessible, fiable et culturellement pertinente.

Avertissement : TengLaafi est un outil éducatif. Consultez toujours un professionnel de santé pour tout diagnostic ou traitement médical.

Recherche sémantique

Embeddings multilingues analysent votre question et identifient les documents les plus pertinents dans la base vectorielle.

Génération contextuelle

Le modèle LLM génère une réponse structurée basée uniquement sur les sources récupérées — pas d'hallucination.

Citations transparentes

Chaque réponse est accompagnée de ses sources avec scores de pertinence, pour vérifier l'exactitude.
